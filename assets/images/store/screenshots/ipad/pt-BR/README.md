# pt-BR iPad screenshot localization

Seven 12.9/13-inch portrait screenshots localized from the approved en-US iPad masters, with wording checked against `../../localized-copy.json` and the approved matching iPhone artwork. The `NEW` pills remain English.

Each selected 1086 × 1448 generation was resized as a whole to 2048 × 2731 with LANCZOS; its bottom row was repeated once for the required 2048 × 2732 RGB JPEG export (quality 94). No inset canvas was used.

Localized source UI crops and all generation attempts are retained in `raw/`. Full-size visual inspection and macOS Vision OCR were used to check the lettering. OCR occasionally omits accents or spaces; those were checked visually against `localized-copy.json`.

Shot 01 was regenerated once because the first attempt used a light emoji board. The selected second attempt uses the master’s dark board with two gold sun cards face up.
