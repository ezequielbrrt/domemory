# Flippo result modal family

These three static phone composites share a 945 × 2048 canvas, the same dimmed gameplay screenshot, 44 px cream card radius, lavender hero panel, rounded display typography, and coral capsule primary button. Flippo changes pose and the content below the hero changes with the outcome; the chrome, spacing, and button location stay aligned. The two new sprites are full-body 1024 × 1024 transparent RGBA assets. This is a proposal, not a changed app screen.

## Win — `mockup-win.png`

This corresponds to `ios/DoMemory/DoMemory/Modules/Memorize/MemorizeView/Modals/WinModal/WinModal.swift`. It uses the approved `.proposals/app-pet-v2/pet2-a-celebrate.png` art over the real `assets/screenshots/6.9/en-US/01_hero_gameplay.jpg` backdrop, then shows **“Congratulations!”**, **“You finished this memorama in time”**, two filled amber stars and one unfilled star, example stats for **pairs**, **remaining**, and **errors** (the app's localized stat labels), **“Next Level”**, **“Share result”**, and **“Menu”**. The supplied brief combines the free-game congratulations copy with the level-mode Next Level action; the current `WinModal.swift` normally uses “Level Cleared!” for a numbered level. This combination is intentional for this visual proposal. No new art prompt was needed for the win pose.

## Out of time — `mockup-lose-time.png` and `flippo-lose-time.png`

This corresponds to the `.outOfTime` branch of `ios/DoMemory/DoMemory/Modules/Memorize/MemorizeView/Modals/LoseModal/LoseModal.swift`, which selects the `clock-crack` hero animation and a timer reason icon. The exact reason copy is **“Sorry, you ran out of time”**, from `game_lose_message` in `ios/DoMemory/DoMemory/en.lproj/Localizable.strings`. The mockup uses that copy inside a timer chip, Flippo's dizzy cracked-clock pose, a three-heart sample row with one heart lost, **“Try again”**, and **“Menu”**. The clock motif belongs to the pose and stays small relative to the card character.

**Pose prompt:** “Use the supplied Flippo idle sprite as the EXACT character identity, proportions, colors, and flat chibi sticker style. Create one new full-body transparent PNG pose for a DoMemory loss caused by running out of time. Keep Flippo unmistakably the same living coral-orange rounded memory card with large cream question mark, small apple emoji exposed under the folded upper-right corner, indigo card layer behind, navy facial features, lavender mitten arms, and amber feet. Give Flippo a startled/dazed but still friendly expression with small spiral or unfocused eyes; raise one lavender mitten near the side of the head. Add only a TINY cracked-clock motif near the raised mitten, smaller than one eye, as a restrained visual cue, not a separate large prop; no lettering or numerals. Center the entire full body within a square canvas with at least 10% transparent padding. Premium clean 2D sticker, gentle cel shading, no pure black outlines. TRUE alpha transparent background, no floor, external shadow, words, text, watermark, or confetti.”

## Consistency choices

Both lose states use the same coral filled primary button and simple Menu text link as the win state, even though the current `LoseModal.swift` uses the secondary color for Try again and an outlined Menu button. Optional rewarded-ad, star-spend, and skip actions are left out of these focused static compositions. The three-heart, one-lost row is an illustrative brief-driven sample; actual level lives are four per day and the screen shows the post-loss count. The new poses used `.proposals/app-pet-v2/pet2-a-idle.png` as their exact identity/style reference, and the two existing Flippo files remain untouched. Pillow handled the alpha framing, hearts, stars, icons, modal layout, and screenshot compositing.
